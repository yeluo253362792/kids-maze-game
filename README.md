# 奇妙迷宫

写给五岁孩子的主题迷宫小游戏（手机/平板触屏）。

## 怎么玩

用手机浏览器打开 `index.html`，或在项目目录运行：

```bash
npx --yes serve .
```

打开首页直接选关，用屏幕下方方向键走到终点。

## 关卡（共 15 关）

| 主题 | 尺寸 | 错路嵌套 |
|------|------|----------|
| 森林小动物 | 10×10 | ≤2 |
| 海底冒险 | 15×15 | ≤2 |
| 星空火箭 | 20×20 | ≤2 |
| 糖果王国 | 15×15 | ≤2 |
| 恐龙乐园 | 15×15 | ≤3 |
| 开心农场 | 15×15 | ≤2 |
| 海盗寻宝 | 20×20 | ≤2 |
| 雪地小屋 | 20×20 | ≤3 |
| 火山探险 | 20×20 | ≤2 |
| 蝴蝶花园 | 25×25 | ≤2 |
| 小火车 | 25×25 | ≤3 |
| 城堡骑士 | 25×25 | ≤2 |
| 沙漠绿洲 | 30×30 | ≤2 |
| 彩虹滑梯 | 30×30 | ≤3 |
| 月亮兔子 | 30×30 | ≤2 |

每关主题、路径种子均不同；全格可走，通关路线唯一。

## 迷宫数据

关卡路径已预计算并保存在 `js/mazes-data.js`。游戏运行时只读取，不再现场生成。

若改了种子或生成算法，重新烘焙：

```bash
node scripts/bake-mazes.js
```
