# 五岁儿童迷宫游戏 — 设计规格

**日期：** 2026-10-22  
**状态：** 已实现（第一版）  
**技术选型：** 单页网页（HTML + CSS + JS），手机/平板触屏优先

---

## 1. 目标与成功标准

为约五岁儿童设计一款主题迷宫小游戏，男女孩都讨喜。

**成功标准：**

- 孩子能在手机/平板上独立完成选关与走迷宫（大按钮、少文字）。
- 每关从起点到终点只有一条成功路线。
- 三关主题鲜明，难度以迷宫尺寸区分，规则一致。
- 通关有简短庆祝，无倒计时、无失败惩罚。

---

## 2. 体验流程

1. **首页** — 标题「奇妙迷宫」+ 大「开始」按钮；柔和彩色氛围背景。
2. **选关** — 三张主题卡片：
   - 🌲 森林小动物（10×10）
   - 🌊 海底冒险（15×15）
   - 🚀 星空火箭（20×20）
3. **游戏中** — 上方全图迷宫；下方四个超大方向键；角落「返回」「重来」。
4. **通关** — 到达终点 → 星星/气球 +「太棒了！」→「下一关」或「再玩一次」。
5. **撞墙** — 角色轻晃，不停罚、不扣分。

---

## 3. 迷宫规则

| 关卡 | 主题 | 尺寸 | 难度定位 |
|------|------|------|----------|
| 1 | 森林小动物 | 10×10 | 适中（路径较短） |
| 2 | 海底冒险 | 15×15 | 适中（路径更长） |
| 3 | 星空火箭 | 20×20 | 适中（路径最长） |

- 地图为格子网格；每格为墙或通路。
- **唯一通路**：每关预置地图，起点→终点仅一条成功路线；可含死胡同。
- 移动：点一次方向键，角色沿该方向移动 **1 格**；撞墙则停在原地并轻晃。
- 无倒计时、无生命值、无失败结局。
- 整张迷宫一屏显示；格子随尺寸缩小，方向键尺寸保持足够大。

---

## 4. 视觉与主题

**整体画风：** 圆润插画感，线条软，颜色明亮但不刺眼；避免写实与暗黑风格。

| 关卡 | 氛围色 | 角色 | 终点 | 墙壁气质 |
|------|--------|------|------|----------|
| 森林 | 草绿 + 暖黄 | 小狐狸 | 树洞小窝 | 树篱 / 木围栏 |
| 海底 | 浅蓝 + 珊瑚粉 | 小海龟 | 闪亮贝壳 | 珊瑚 / 海草 |
| 星空 | 靛蓝 + 浅紫星光 | 小火箭 | 亮晶晶星球 | 星云轨道围栏 |

**通关反馈：** 1～2 秒简短庆祝（星星/气球 +「太棒了！」），然后操作按钮。

**文案：** 中文；尽量少字；按钮可用图标 + 短词（开始、重来、返回、下一关）。

## 5. 技术结构

```
/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js          # 页面流转、事件绑定
│   ├── maze-core.js     # 移动、碰撞、通关检测
│   ├── render.js        # 迷宫与角色绘制
│   └── levels.js        # 三关地图数据（二维数组）
└── docs/superpowers/specs/...
```

- **运行方式：** 静态文件；手机浏览器打开即可（本地或任意静态托管）。
- **绘制：** 使用 **DOM 格子网格**（每个格子一个元素），便于主题换肤与无障碍适配；主题用 CSS 变量 + 简单 SVG/emoji 图标。
- **关卡数据：** JS 内二维数组编码墙/路/起点/终点；实现时用脚本或手工 BFS 校验唯一通路。
- **输入：** 屏幕四大方向触控按钮；额外兼容键盘方向键（家长电脑试玩）。
- **状态：** 当前关卡、角色坐标、通关态；「重来」重置坐标；第一版用 `localStorage` 标记已通关（选关卡片显示小勾）。
- **音效：** 第一版不加音效，避免自动播放与静音策略复杂度。
- **明确不做：** 账号、联网、广告、音效、PWA。

---

## 6. 范围边界（YAGNI）

**第一版包含：** 首页、选关、三关迷宫、方向键移动、撞墙反馈、通关庆祝、重来/返回/下一关。

**第一版不包含：** 更多主题、计时排行、贴纸收集、剧情对话、多语言、PWA 安装包、后端。
